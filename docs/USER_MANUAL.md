# Silver Voice 사용자 매뉴얼

## Silver Voice란?

Silver Voice는 글쓰기가 어려운 어르신들을 위해 **음성 대화만으로 이력서를 작성**할 수 있는 앱입니다. 마이크 버튼을 누르고 말씀하시면 AI가 대화를 통해 이력서를 완성하고, 맞춤 일자리까지 추천해 드립니다.

---

## 화면 구성

앱 하단에 4개의 탭이 있습니다:

| 탭 | 아이콘 | 기능 |
|----|--------|------|
| 일자리 | 서류가방 | AI가 추천하는 일자리 목록 |
| **홈** | 집 | **음성으로 이력서 작성** (메인 화면) |
| 이력서 관리 | 문서 | 작성된 이력서 확인 및 수정 |
| 마이페이지 | 사람 | 설정 및 계정 정보 |

---

## 이력서 작성하기 (홈 화면)

### 순서

1. 앱을 열면 **홈 화면**이 표시됩니다.
2. 화면 아래의 큰 **파란색 마이크 버튼**을 확인합니다.
3. 상태 표시가 "버튼을 누른 채로 대화를 시작하세요"인지 확인합니다.

### 말하기

1. 마이크 버튼을 **꾹 누른 채로** 말씀하세요.
2. 버튼이 **빨간색**으로 바뀌고 "듣고 있어요..."가 표시됩니다.
3. 말씀이 끝나면 **손을 떼세요**.
4. AI가 답변을 준비합니다 ("AI가 생각하는 중입니다...").
5. AI가 음성 또는 텍스트로 답변합니다.

### AI가 물어보는 항목

AI는 아래 6가지 정보를 순서대로 여쭤봅니다:

| 순서 | 항목 | 예시 답변 |
|------|------|-----------|
| 1 | 이름 | "홍길동입니다" |
| 2 | 나이 | "65살이에요" |
| 3 | 거주지 | "서울 강남구에 살고 있어요" |
| 4 | 경력 | "삼성전자에서 20년 일했어요" |
| 5 | 희망 근무 형태 | "주 3일 시간제가 좋겠어요" |
| 6 | 건강 상태 | "건강하지만 무릎이 조금 불편해요" |

### 진행 상태 확인

- 홈 화면 하단에 **이력서 완성도**가 퍼센트로 표시됩니다.
- 아직 입력하지 않은 항목은 **주황색 태그**로 표시됩니다.
- 모든 항목이 채워지면 100%가 됩니다.

---

## 이력서 수정하기 (이력서 관리 탭)

음성 인식이 정확하지 않은 경우, 직접 수정할 수 있습니다.

### 순서

1. 하단 탭에서 **이력서 관리**를 누릅니다.
2. 수정하고 싶은 항목의 **입력칸**을 누릅니다.
3. 키보드가 나타나면 내용을 수정합니다.
4. 수정이 끝나면 **변경사항 저장** 버튼을 누릅니다.
5. "이력서가 저장되었습니다" 메시지가 나타납니다.

### 이력서 초기화

처음부터 다시 작성하고 싶으면:

1. 이력서 관리 화면 우측 상단의 **초기화** 버튼을 누릅니다.
2. 확인 대화 상자에서 **확인**을 누릅니다.
3. 모든 내용이 삭제되고 처음부터 다시 시작합니다.

---

## 일자리 추천 (일자리 탭)

이력서가 모두 작성되면 AI가 맞춤 일자리를 추천합니다.

### 순서

1. 하단 탭에서 **일자리**를 누릅니다.
2. AI가 이력서를 분석하여 적합한 일자리를 보여줍니다.
3. 각 일자리 카드에는 다음 정보가 표시됩니다:
   - AI 매칭 점수 (%)
   - 직종 이름
   - 회사명 및 위치
   - 근무 형태
   - AI 추천 이유
4. **지원하기** 버튼을 눌러 지원할 수 있습니다.

### 일자리 상세 보기

일자리 카드를 누르면 상세 화면으로 이동합니다. 한국노인인력개발원 100세누리 공공데이터에서 가져온 실제 채용 정보를 함께 볼 수 있습니다.

---

## 상태 표시 안내

마이크 버튼 위에 현재 상태가 표시됩니다:

| 표시 | 의미 | 할 일 |
|------|------|-------|
| 버튼을 누른 채로 대화를 시작하세요 | 준비 완료 | 마이크 버튼을 꾹 누르세요 |
| 듣고 있어요... (손을 떼면 완료) | 녹음 중 | 말씀을 계속 하세요 |
| AI가 생각하는 중입니다... | 처리 중 | 잠시 기다려 주세요 |
| AI가 답변하고 있습니다... | AI 답변 중 | AI 답변을 들어주세요 |
| 서버와 연결이 끊어졌습니다 | 연결 끊김 | 재연결 시도 버튼을 누르세요 |

---

## 문제 해결

### 마이크 버튼이 회색이에요

서버와 연결이 되지 않은 상태입니다.
- **재연결 시도** 버튼을 눌러보세요.
- 인터넷 연결을 확인해 주세요.

### 음성 인식이 정확하지 않아요

- 조용한 곳에서 사용해 주세요.
- 마이크에 가까이 대고 또박또박 말씀해 주세요.
- 이력서 관리 탭에서 직접 수정할 수 있습니다.

### 일자리가 안 나와요

- 이력서 6개 항목이 모두 작성되었는지 확인해 주세요.
- 홈 화면에서 이력서 완성도가 100%인지 확인해 주세요.
- 일자리 탭에서 아래로 당겨 새로고침해 보세요.

### 앱이 멈췄어요

- 앱을 완전히 종료한 후 다시 실행해 주세요.
- 문제가 계속되면 앱을 삭제 후 다시 설치해 주세요.
